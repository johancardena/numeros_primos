Flutter - Números Primos

## Descripción

Este ejercicio fue una práctica con instalación y primeros pasos con Flutter. La aplicación consiste en un botón que, al ser presionado, genera y muestra los números primos comprendidos entre 1 y 100.

## Objetivos

* Instalar y configurar Flutter.
* Verificar el entorno de desarrollo.
* Crear un proyecto Flutter desde cero.
* Modificar la aplicación de ejemplo.
* Implementar un algoritmo para identificar números primos.
* Publicar el proyecto en GitHub.


# Instalación de Flutter

## 1. Descarga del SDK

Se descargó el Flutter SDK para Windows desde el sitio oficial de Flutter.

## 2. Configuración del entorno

Se agregó la carpeta `flutter/bin` a las variables de entorno del sistema para poder ejecutar comandos de Flutter desde cualquier terminal.

# Desarrollo de la Aplicación

Se modificó el archivo:

```text
lib/main.dart
```




La aplicación incluye:

* Un botón llamado "Mostrar Números Primos".
* Una función para determinar si un número es primo.
* Una función para generar los números primos entre 1 y 100.
* Un área de texto donde se muestran los resultados.

# Ejecución del Proyecto

Para ejecutar la aplicación:

```bash
flutter run
```

O para ejecutarla en Google Chrome:

```bash
flutter run -d chrome
```
